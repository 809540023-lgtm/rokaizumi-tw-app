01

MESSAGE / 提言の原点

技術は、制度と信頼に支えられて、
はじめて社会の基盤になる。

AIは人を置き換えるための技術ではなく、現場の知恵を増幅するための技術です。ブロックチェーンもまた、投機のための道具ではなく、人と人、企業と地域のあいだに「検証できる信頼」を積み上げるための社会インフラです。

私は台湾で生まれ、金融、IT、小売、越境EC、ブロックチェーン、AIの現場を30年歩いてきました。その中で学んだのは、技術の価値は「実装の質」で決まるということです。どんなに優れた技術も、現場の業務、法制度、会計、人材の納得がなければ、社会には定着しません。

日本には、世界に誇る現場力、高い倫理観、そして長期の信頼があります。足りないのは、それをデジタルの力で全国へ、そして世界へつなぐ「実装の設計図」ではないでしょうか。

私は、政策と技術、事業と地域のあいだに立ち、絵に描いた政策を、動く産業に変える仕事をしたいと考えています。日本と台湾、そしてアジアの知恵を結び、次の時代の産業基盤を、ともに設計してまいります。

信頼を、実装する。

信頼なき技術は、社会を変えない。 実装なき政策は、未来をつくらない。

04

BLOCKCHAIN IN JAPAN / 日本での展開

ブロックチェーン産業の日本での展開「投機」から「実装」へ。

世界のブロックチェーン産業は、投機の時代を終え、実物資産の流動化と地域経済の再構築へと向かっています。日本は、法制度、実物資産、地域金融という三つの厚みを持つ、世界でも稀な実装大国です。

制度

整備される
トークン化の枠組み

金融庁を中心に、暗号資産やトークン化資産を金融商品取引法の枠組みで捉える議論が進んでいます。信託受益権を用いた不動産ST、不動産特定共同事業法に基づく商品など、実務の選択肢が広がっています。

市場

大阪・関西万博が
開いた扉

2025年の大阪・関西万博を契機に、Web3とデジタル資産への関心は全国へ広がりました。大阪は、制度・産業・国際性を併せ持つ、アジア有数の実証拠点になり得ます。

課題

実証と事業の
あいだにある溝

規制の複雑さ、専門人材の不足、会計・税務・セキュリティの整備。日本には高度な実証が数多くありますが、事業として継続するための設計が不足しています。

機会

地域資産を、
地域外の長期資金へ

地方の不動産、観光、農林水産、福祉、伝統産業。小口化と流動化によって、これまで動かなかった資産に、長期の資金と新しい担い手を呼び込めます。

CASE / OSAKA RWA PROJECT

大阪の一戸建てから、
日本のRWAモデルを設計する。

大阪の一戸建てを対象に、信託受益権を用いたRWAの執行戦略を研究し、日本語版ホワイトペーパー（v3.4）をまとめました。実物資産の所有と受益を分離し、法制度に沿って権利を記録する。その設計を通じて、小規模案件でも法務・受託コストを透明化し、地域の資産を長期資金と結ぶ方法を検証しています。

現在は研究・シミュレーション段階であり、投資募集・勧誘を行うものではありません。弁護士、受託者、会計・税務の専門家による検証を通過することが、次の段階の前提です。現時点の研究設計では、海外限定、流通ロック、内部名簿を組み合わせ、規制を前提とした構造を検討しています。

05

ROADMAP / 日本での将来計画

大阪で生まれたモデルを、
日本とアジアの基盤へ。

大阪で生まれた実装モデルを、地域金融、産業、人材、国際連携へと広げます。政策と事業のあいだに、検証可能なステップをつくることが私たちの方法です。

PHASE 1 / 2026–2027

大阪モデルの実証

  • 法務・会計・税務・セキュリティの専門家連携
  • 大阪府ブロックチェーン協会との政策対話（予定）
  • 募集を行わないシミュレーションと、適法な枠組みでの小規模実証

PHASE 2 / 2027–2028

地域金融 × RWA

  • 地方銀行・信用金庫・不動産業者との連携
  • 中小企業の資産流動化モデルの確立
  • 観光・福祉・農林水産・伝統産業への横展開

PHASE 3 / 2029–2030

アジアの実装ハブへ

  • 大阪をアジアのRWA実装ハブに
  • 台湾・ASEAN・欧州の投資家・技術者との接続
  • 標準化、人材育成、国際規制対話

日本政府への三つの提言

  1. 01

    規制サンドボックスと専門家連携の常設化

    技術者、弁護士、会計士、税理士、監督官庁が同じテーブルで検討できる常設の場を設ける。個別案件の事前相談を、制度改善の知見へと変える仕組みが必要です。

  2. 02

    地域資産のRWA実証支援

    中小企業・地域金融・自治体が連携する小規模実証に対し、専門家費用と法務費用を支援する。成功事例を横展開できる共通フォーマットの整備を提言します。

  3. 03

    AIガバナンスと計算コストの標準化

    政府・自治体のAI利用において、コストの可視化、監査ログ、データ保護、人材育成を標準化する。AIを「高価な実験」から「持続可能な行政基盤」へ変えるべきです。
